# PRD — Essence by Aditi (essencebyaditi.com)

## 1. Vision
Build the digital home of Dr. Aditi Varekar Khatate's personal brand "Essence by Aditi" — the foundation for a future flagship Ayurvedic clinic and a formulations/supplement company.

## 2. Users
- **Patients (primary)**: women 22–45 in Navi Mumbai/Thane/online, searching hair-fall, skin, PCOS solutions
- **Referrers**: existing patients sharing the site
- **Partners/brands**: Ayurvedic companies evaluating affiliate/partnership
- **Future investors/press**: assessing the brand's credibility

## 3. Goals (v1 — static-first)
| Goal | Metric |
|---|---|
| Rank for local + condition keywords | Top 3 for "ayurvedic doctor navi mumbai", "PCOS ayurveda kharghar" in 6 months |
| Capture leads | Newsletter signups + appointment requests |
| Build authority | Physician-written journal, credentials page |
| Enable monetisation later | Partner/affiliate section scaffolded |

## 4. Features (shipped v1)
- Multi-page site: Home, About, Services, Journal (blog), Contact
- Appointment request form → MongoDB (Calendly env hook ready)
- Newsletter capture → MongoDB (exportable; migrate to Beehiiv/Mailchimp later)
- 5 SEO-optimized physician-written articles (static, Sanity-ready data shape)
- Brand kit: logo, colors (blue/lavender), typography, glass-fluid design system
- SEO: JSON-LD Physician schema, sitemap.xml, robots.txt, OG/Twitter cards, canonical
- Full responsive + reduced-motion support

## 5. Out of scope (v1)
Payments, patient portal, e-commerce, CMS integration (Sanity planned), multilingual (Marathi/Hindi planned).

## 6. Roadmap
- **P1**: Calendly link live, Sanity CMS, Google Business Profile, real testimonials with consent, WhatsApp click-to-chat
- **P2**: Affiliate links live, Marathi/Hindi versions, video content embed (YouTube), online payment for consults
- **P3**: E-commerce for own formulations, patient login, tele-consult platform
