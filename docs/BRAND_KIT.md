# Brand Kit — Essence by Aditi

## Story
"Essence" = the irreducible core Ayurveda restores. The brand is calm, clinical and quietly luxurious — a physician's brand, not an influencer's.

## Logo
- Mark: fluid one-line droplet-lotus (blue→lavender gradient) — `frontend/public/images/logo.png`
- Wordmark: "Essence" in Playfair Display SemiBold + "by Aditi" in Playfair Italic, slate-500
- Clearspace: 0.5× mark height. Never stretch, recolour outside palette, or place on busy photos.

## Palette
| Token | Hex | Use |
|---|---|---|
| Essence Blue | #1E3A8A | headings, primary buttons, trust |
| Vivid Blue | #2563EB | links, hover, accents |
| Lavender Mist | #E0E7FF | soft backgrounds |
| Periwinkle | #C7D2FE | glass tints, borders |
| Cloud | #F8FAFC | page background |
| Ink | #0F172A | body headings (never pure black) |
| Deep Navy | #0F1D4E | dark sections/footer |

## Typography
- Display: **Playfair Display** (400–700, italics for emphasis words)
- Body/UI: **Manrope** (300–700)
- Overlines: Manrope 600, uppercase, letter-spacing 0.25em, 12px

## Voice & tone
Calm authority. "We treat the root; radiance follows." Evidence-aware, never mystical-vague, never salesy. Sanskrit terms always translated in-line.

## Visual language
Light backgrounds, glassmorphism (70% white, 24px blur), fluid lavender-blue gradient blobs, 2–3% grain, generous whitespace, rounded-3xl radii, serif italic accent words in blue.

## Social templates (IG/FB/YT/LinkedIn)
- Handle everywhere: **@essencebyaditi**
- Grid ratio: educational carousel (lavender bg, Playfair headline) : reel : patient-story = 3:2:1
- Bio line: "Ayurveda for hair, skin & hormones · BAMS, MD · Navi Mumbai · Book ↓"
